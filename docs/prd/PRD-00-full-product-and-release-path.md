# PRD 00：满血版产品方案与分阶段上线落地路径

- **所属总 PRD**：《学霸奇遇记：知识战场》
- **版本**：v1.0 / 可上线发布版
- **负责人**：小P
- **目标读者**：polaw、小顾、小架、小码、小质
- **定位**：本文件是满血产品总方案。分阶段是工程落地路径，不是降低产品闭环。

---

## 1. 需求 / 问题

老板已明确：产品目标不是短期演示型样板，而是一个本地 H5 单人主线可上线发布的寓教于乐成品。

因此，产品必须从“会闯关 + 会报告”的基础体验，升级为完整闭环：

```text
孩子答题 → 战斗变强 → 发现薄弱点 → 生成怪兽/悬赏/复习副本 → 掌握度成长
→ 解锁宠物/装备/徽章/知识基地 → 地图继续探索 → 家长报告解释学习产出
→ 家长轻量参与与表扬 → 孩子回到下一次主动学习
```

核心产品判断：

> 学习不是游戏的中断；学习结果要成为世界、角色、怪兽、任务和亲子反馈的一部分。

---

## 2. 产品目标

### 2.1 对孩子

- 觉得自己是在玩一个有主线、有收集、有成长、有惊喜的知识冒险游戏。
- 做题正确能直接变强，答错不会挫败，而是生成可击败、可收集、可复仇的“错题怪兽”。
- 每天 10-20 分钟能完成一段清晰冒险，并愿意第二天回来继续。

### 2.2 对家长

- 明确看到孩子练了什么、哪里薄弱、掌握度如何变化。
- 报告不是孤立图表，而能反哺孩子的任务：悬赏、复习副本、表扬卡、家长 Boss 出题。
- 产品本地优先、轻量可控，不引入大型网游、陌生人社交、付费诱导。

### 2.3 对研发 / 发布

- 首发版是完整闭环成品：主线地图、战斗、错题怪兽、掌握成长、收集养成、家长报告和轻量亲子互动都必须可用。
- 上线后增强聚焦内容量、表现力、学科 Boss 差异化、运营活动，而不是补核心闭环。

## 4. 首发必须上线范围

### 4.1 体验闭环 P0

1. 孩子进入主线地图，选择已解锁关卡。
2. 关卡内通过知识补给获得弹药、护盾、技能、大招能量。
3. 战斗中支持 Combo、补救一击、Boss 护盾/弱点窗口。
4. 答错题进入错题怪兽图鉴，按知识点聚合。
5. 系统基于薄弱点生成悬赏任务和复习副本。
6. 完成复习后更新掌握度、知识战力、图鉴净化状态。
7. 通关/复习后产出战后高光：最强 Combo、补救成功、掌握升级、击败怪兽。
8. 奖励进入宠物、装备、徽章、知识基地等收集系统。
9. 家长报告展示今日/近 7 日学习数据，并一键生成或推荐孩子任务。
10. 家长可本地生成表扬卡，或轻量出一道 Boss 题给孩子挑战。

### 4.2 首发内容量建议

| 内容 | 首发底线 | 可上线后增强 |
|---|---:|---|
| 年级 | 至少 1 个完整年级体验链路 | 扩展 1-6 年级全主线 |
| 学科 | 数学主线必须完整；语文/英语可接通基础玩法 | 学科专属 Boss 与事件 |
| 章节 | 至少 1 个完整星球 / 3 章 / 每章 Boss | 更多星球和剧情 |
| 错题怪兽 | 至少 12 种模板 + 按知识点换肤 | 稀有怪、进化形态 |
| 悬赏任务 | 今日薄弱点、错题复仇、Boss 破盾 3 类 | 周悬赏、连续任务 |
| 宠物装备徽章 | 每类至少可获得、可查看、可装备/展示 | 套装、强化、图鉴成就 |
| 地图事件 | 宝箱、岔路挑战、NPC 提示 3 类 | 随机事件池扩展 |
| 家庭互动 | 表扬卡、家长 Boss 出题、本地记录 | 亲子挑战模板扩展 |

> 说明：首发内容量可以控制，但每条闭环必须跑通，不能只做入口或静态占位。

## 5. 分阶段上线落地路径

### Phase A：核心系统打通（内部可玩）

目标：孩子能完整玩完“主线关卡 → 战斗 → 结算 → 报告”。

交付：
- 地图关卡配置与解锁。
- 知识补给资源规则。
- 射击战斗、Boss 护盾、星级结算。
- 基础报告接口与页面。

验收：
- 从首页开始，15 分钟内无需开发介入完成 1 章普通关 + Boss。
- 所有答题记录、错题、掌握度、报告数据能落库并回读。

### Phase B：学习闭环满血化（首发候选）

目标：错误、薄弱点和掌握度进入游戏世界。

交付：
- 错题怪兽图鉴。
- 薄弱点悬赏任务。
- 补救一击、战后高光。
- 掌握度升级与知识战力。
- 家长报告反哺任务。

验收：
- 答错 2 道同知识点题后，图鉴生成对应怪兽，报告识别薄弱点，并出现悬赏任务。
- 完成悬赏后，掌握度和怪兽状态发生可见变化。

### Phase C：成长收集与探索惊喜（首发发布版）

目标：形成可发布的留存与收集体验。

交付：
- 宠物、装备、徽章、知识基地。
- 地图宝箱、分支挑战、NPC/事件。
- 亲子表扬卡、家长 Boss 出题。
- 上线埋点、错误日志、关键数据看板或本地导出。

验收：
- 孩子完成 3 天学习后，至少能看到 3 类成长变化：知识战力、收集物、基地/图鉴。
- 家长能从报告一键发起表扬或 Boss 出题，孩子侧能收到并完成。

### Phase D：上线后增强

目标：在不改变核心架构的前提下扩内容、提表现。

增强项：
- 更多星球、章节、Boss、学科机制。
- 更丰富怪兽形态、宠物技能、装备套装。
- 周报/月报、更多家庭互动模板。
- 更细埋点分析、内容难度自适应。

## 6. 不做范围 / 风险边界

首发仍保持“本地 H5 单人主线可发布”，明确不做：

1. 不做大型网游、公会、排行榜、陌生人社交。
2. 不做付费抽卡、诱导消费、商业化商城。
3. 不做复杂账号体系、云同步、跨设备家庭组织。
4. 不做开放式 UGC 题库发布；家长 Boss 出题仅本地保存、本机使用。
5. 不做无法解释的 AI 自动评分闭环；涉及学习判断必须有规则口径和可回溯数据。
6. 不把失败惩罚做重，避免儿童挫败和家长反感。

## 7. 上线验收清单

### 7.1 产品验收

- [ ] 首次进入有明确继续冒险入口。
- [ ] 地图节点状态正确：锁定 / 可挑战 / 已通关 / Boss / 分支。
- [ ] 答题正确能获得战斗资源，答错能进入错题链路。
- [ ] 战斗中 Combo、补救一击、Boss 机制至少各有 1 个可见效果。
- [ ] 结算页展示战后高光、星级、奖励、掌握变化。
- [ ] 错题怪兽图鉴能新增、查看、复习、净化。
- [ ] 薄弱点悬赏任务能生成、完成、领取奖励。
- [ ] 宠物/装备/徽章/知识基地至少各有一个可获得结果。
- [ ] 家长报告能展示今日与近 7 日，并能反哺任务。
- [ ] 表扬卡和家长 Boss 出题能本地闭环。

### 7.2 数据与可观测性验收

- [ ] 关键行为有埋点：进入地图、开始关卡、答题、战斗结算、报告打开、悬赏生成/完成、图鉴查看、家庭互动。
- [ ] 关键错误有日志：题目加载失败、提交失败、报告失败、存档失败、资源结算异常。
- [ ] 本地数据表支持迁移，不破坏已有错题和关卡记录。
- [ ] 可用测试脚本生成一段完整学习数据并验证报告。

### 7.3 儿童安全与家长信任验收

- [ ] 无付费诱导、无外部社交入口。
- [ ] 家长 Boss 题仅本地可见，默认不上传。
- [ ] 失败文案不羞辱孩子，错题怪兽表达为“可战胜的挑战”。
- [ ] 游戏奖励不覆盖学习事实，报告主轴仍是知识点和掌握度。

## 8. 指标

### 8.1 首发核心指标

- 关卡完成率：开始关卡后完成结算比例。
- 次日回访率：本地可用最近使用日期粗略判断。
- 学习有效题量：每日完成题数、中位正确率。
- 薄弱点修复率：被识别薄弱点在 7 日内完成复习的比例。
- 家长报告打开率：完成关卡后打开报告比例。
- 任务反哺转化率：从报告点击推荐任务并完成的比例。

### 8.2 质量指标

- 题目加载成功率。
- 答题提交成功率。
- 报告接口成功率。
- 本地存档读写成功率。
- 首屏可交互耗时。

## 是否需要老板拍板

需要老板拍板两点：

1. 首发内容量底线：建议先完整打磨“数学 1 个星球 / 3 章 / 每章 Boss”，其他年级学科以可接入为准。
2. 家长 Boss 出题边界：建议仅本地轻量手输/选择题，不做拍照出题自动发布和云端共享。
