
## homework-tutor P1 duplicate answer/mastery fix
- Symptom: 3-question supply smoke produced inflated `level_run_answers` after finish because frontend submitted each supply answer via `submitSupply`, then `finishLevelRun` sent `stats.answers`/`wrongQuestions` and backend `finishHandler` inserted them again and called `updateMastery` again.
- Root cause: `lib/level-api.js` had overlapping ownership: `submitSupplyHandler` and `finishHandler` both wrote answer rows/mastery. This corrupted answer detail counts and mastery attempts.
- Fix: make `submitSupplyHandler` the sole owner of supply/Boss answer detail, wrongbook insertion, resource reward, and mastery update. `finishHandler` now only writes `level_runs`/progress/rewards and computes correct/wrong/accuracy from already stored `level_run_answers` when present, ignoring replayed `payload.answers` for answer/mastery writes.
- Regression: `test/campaign-api.test.js` now verifies 3 submitted answers remain 3 after finish, mastery attempts remain 3, and finish ignores spoofed `correctCount/wrongCount` when stored answers exist.
- Verification: `npm test` => 85 pass / 0 fail. Repro smoke after fix: before finish `{answers:3, attempts:3, wrongbook:1}`, after finish `{answers:3, attempts:3, wrongbook:1, correct:2, wrong:1}`.
