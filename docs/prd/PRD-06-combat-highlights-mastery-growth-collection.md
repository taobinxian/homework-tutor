# PRD 06：战斗高光、掌握度升级与成长收集系统

- **所属总 PRD**：《学霸奇遇记：知识战场》
- **版本**：v1.0 / 满血首发上线版
- **负责人**：小P
- **目标读者**：研发、测试、产品

---

## 1. 需求 / 问题

只做“答题给资源”还不够满血。孩子需要在每场战斗里获得即时爽感，并在多天学习后看到长期成长。

本 PRD 定义三条体验线：

1. **战斗即时反馈**：Combo、补救一击、战后高光。
2. **学习成长反馈**：掌握度升级、知识战力。
3. **长期收集反馈**：宠物、装备、徽章、知识基地。

---

| 模块 | 首发必须做 | 上线后增强 |

## 3. 战斗即时反馈

### 3.1 Combo 规则

| 行为 | 结果 |
|---|---|
| 连续答对 | combo +1 |
| 答错 | combo 清零，但可触发补救一击 |
| combo = 3 | 额外弹药 / 小特效 |
| combo = 5 | 技能能量 / 战后高光 |
| combo ≥ 8 | 大招能量 / 稀有高光 |

结算记录：`maxCombo`、`comboBreakCount`、`comboBonusResources`。

### 3.2 补救一击

目标：降低儿童答错挫败感，把错误变成“还有机会”。

触发：
- 普通题答错后，若该关补救次数未用完，弹出 1 道同知识点简化题或原题提示题。

结果：
- 补救成功：不改写原题错题记录，但给予“补救成功”高光，怪兽不强化或少强化。
- 补救失败：正常记录错题，怪兽强化。

限制：
- 每关默认 1 次免费补救。
- 宠物或装备可增加补救次数，但首发最多 2 次，避免刷奖励。

### 3.3 战后高光

结算页最多展示 3 条，优先级：

1. 掌握度升级：例如“5以内加法 从 巩固中 → 已掌握”。
2. 击败/净化错题怪兽。
3. 最高 Combo。
4. 补救一击成功。
5. Boss 破盾或低血量反杀。
6. 获得稀有奖励。

## 4. 掌握度升级与知识战力

### 4.1 掌握度状态

| 状态 | 条件建议 | 展示 |
|---|---|---|
| 未开始 | 无答题记录 | 灰色 |
| 学习中 | 有记录但样本不足 | 蓝色 |
| 薄弱 | 正确率 < 60% 或连续错 | 红/橙 |
| 巩固中 | 正确率 60%-84% | 黄色 |
| 已掌握 | 近 5 题正确率 ≥ 80% 且最近无连续错 | 绿色/发光 |

### 4.2 数值计算建议

首发可用 0-100 分：

```text
masteryScore = clamp(基础分 + 正确率贡献 + 连续正确贡献 - 最近错误惩罚, 0, 100)
```

状态映射：
- 0：未开始。
- 1-39：薄弱。
- 40-69：学习中/巩固中。
- 70-84：巩固中。
- 85-100：已掌握。

### 4.3 知识战力

知识战力用于孩子侧表达学习成长，不替代家长报告的真实数据。

```text
知识战力 = Σ(知识点 masteryScore * 权重) + 徽章加成 + 宠物/装备轻加成
```

限制：
- 家长报告必须展示真实正确率和掌握状态，不只展示战力。
- 装备加成不能让未掌握知识点显示为已掌握。

## 5. 成长收集系统

### 5.1 宠物

首发字段：
- petId、name、level、xp、skill、equipped。

首发宠物技能：
- 增加少量初始护盾。
- 每关一次提示。
- 悬赏奖励 +5%。

### 5.2 装备

装备槽位：武器、护盾、芯片。

属性：
- `ammoBonus`
- `shieldBonus`
- `rescueChance`
- `bossDamageBonus`

约束：属性只影响战斗体验，不改变学习正确率和掌握度原始口径。

### 5.3 徽章

首发徽章类型：
- 首次通关。
- 连对 5 题。
- 净化 1 只错题怪兽。
- 某知识点已掌握。
- 家长表扬卡获得。

### 5.4 知识基地

知识基地是“我学会了什么”的可视化空间。

首发模块：
- 已掌握知识点生成基地建筑。
- 悬赏奖励给基地材料。
- 徽章可陈列在基地墙。

## 6. 数据与接口建议

### 6.1 表

- `mastery`：若已有则扩展 `score/status/updated_at`。
- `player_inventory`：宠物、装备、材料、徽章统一库存。
- `player_loadout`：当前装备和宠物。
- `knowledge_base_items`：基地建筑/装饰。
- `battle_highlights`：战后高光记录。

### 6.2 接口

- `GET /api/growth/summary?user=default`
- `GET /api/inventory?user=default`
- `POST /api/loadout/equip`
- `GET /api/knowledge-base?user=default`
- `POST /api/knowledge-base/place`
- `GET /api/runs/:runId/highlights`

## 8. 验收标准

- [ ] 连续答对能累积 Combo，答错后 Combo 清零。
- [ ] 答错后可触发补救一击，补救成功与失败记录清晰。
- [ ] 结算页能展示最多 3 条战后高光，且优先级正确。
- [ ] 同一知识点多次练习后，掌握度状态能升级或降级。
- [ ] 知识战力随掌握度和收集奖励变化。
- [ ] 宠物、装备、徽章、知识基地均可获得并持久化。
- [ ] 家长报告展示真实学习数据，不被装备加成污染。
